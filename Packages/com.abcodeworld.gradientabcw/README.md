# Gradient ABCW

A 32-key colour/alpha gradient for Unity with evaluation-time modulation (reverse, repeat
domain mapping, hue/saturation/brightness/alpha adjustment), a Burst-compiled evaluation core,
and a pure UI Toolkit editor (inspector field, property drawer, and a picker window with an
asset library and mesh/texture colour sampling).

See the package documentation (in progress) and the `Samples~/BasicUsage` sample for usage.
